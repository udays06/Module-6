# InkSpire Pro - Full Stack Blog Application

[![Deploy to Vercel](https://vercel.com/button)](https://vercel.com/new)
[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://netlify.com)

InkSpire is a production-ready, fully responsive full-stack blog platform built with Tailwind CSS, Lucide icons, and robust client-side storage persistence.

## Project File Structure

```text
inkspire-blog/
├── index.html        # Main HTML layout & view templates
├── style.css         # Custom utility styles & glassmorphism
├── script.js         # Core application logic & reactive state
├── package.json      # Project dependencies & scripts
├── vercel.json       # Vercel zero-config routing configuration
└── README.md         # Professional documentation & guide
```

## Features

1. **Modern Explorer Feed**: Category filtering, live search bar, featured hero banner, and reading time estimates.
2. **Interactive Post Detail**: Rich typography, like/clap counters, social sharing, and threaded comments.
3. **Author Dashboard**: Track total views, likes, and published posts with quick edit and delete tools.
4. **Client-Side Persistence**: Fully working right out of the box using `localStorage`.

## Quick Start & Deployment

1. Download all files into a local directory.
2. Run `npm install` and `npm start` or simply open `index.html` in your browser.
3. Deploy instantly to Vercel or Netlify by uploading the folder.
